## 포트폴리오가 두 개인 이유

같은 사실과 프로젝트를 지원 산업에 맞춰 두 가지로 보여 줍니다. 내용과 증거는 같고, 첫 화면 문장, 강조하는 경력, 프로젝트 순서만 다릅니다.

- **제약·바이오용**: 백신 마케팅과 품질 관련 경험을 앞에 두고, PharmaFlow Bio(백신 QA)를 첫 프로젝트로.
- **해외영업·사업기획용**: 해외 고객 응대(연 100팀 이상)와 AI 업무 자동화를 앞에 두고, 부품 발주 시점 대시보드를 첫 프로젝트로. 'LS 여정'은 두 사이트 모두 04번 구역에 있습니다.

## 포트폴리오에서 볼 곳 (제약·바이오용 번호 기준)

- **04 LS 여정**: 단계 6개(데이터 기초, 프로젝트1, 바이브 코딩과 AI 작업 규칙, 프로젝트2, 업무 자동화, 프로젝트3). 단계마다 배운 것, 달라진 점과 증거, 내가 한 일 / 팀 / Claude를 나눠 적었습니다.
- **03 프로젝트**: 프로젝트1(부품 발주 시점 대시보드), 프로젝트2(PharmaFlow Bio), 프로젝트3(안물어, 피싱 대응 훈련). 기획 흐름(발견 → 진짜 문제 → 관점 → 해법 → 확인)과 역할 분담.
- **사이드 프로젝트 서가**: Claude와 한 기획과 AI 설계 노트(작업 규칙과 스킬 17개, 시장조사 툴킷 등).

## 내가 한 일 / 팀 / Claude

- 프로젝트1: 조장, 전처리, 부품별 고장 예측 모델, 대시보드 통합(기여도 35%) / 팀원 2명이 나머지 화면과 분석 / Claude Code가 화면 구현, 테스트로 확인
- 프로젝트2: 문제 정의, 인터뷰 설계와 현직자 인터뷰, 화면 개편, 발표 자료 / 팀원 2명이 DB, 서버, AI 기능, 시험 보고서 / Claude Code가 문서와 구현
- 프로젝트3: 판정 규칙, 정답 샘플 채점, 위키 챗봇, 문자 문구, QA 기록, 화면 개편 / 팀원 3명이 앱 뼈대와 DB, 발송, 데이터 수집, 발표와 AI 인터뷰 / Claude Code가 구현과 검토, 서버 AI가 문구 초안을 쓰고 사람이 승인
- 개인 작업(규칙, 스킬, 이 사이트): 방향과 판단, 사실 확인은 내가 / 초안, 코드, 비평은 Claude
